# 客户端连锁采集（Client-Side Vein Miner）

**版本 0.1** ｜ Minecraft **1.21.11** ｜ Fabric ｜ **纯客户端**模组

**一句话**：按住一个热键、准星指着方块，模组就把视野里**整组同种方块**用白色轮廓画出来并显示数量；你挖掉其中任意一块，其余目标按**模拟真实挖掘**逐个挖掉，可触及的标绿、够不到的标红，并随你移动实时刷新。

- modid：`client_vein_miner`
- 仓库：<https://github.com/C8L8M/client-vein-miner>
- 英文文档：[README.md](README.md)

## 一、使用流程（默认键位）

| 步骤 | 操作 | 表现 |
| --- | --- | --- |
| 1 | 按住 **`` ` ``**（触发热键）并指向方块 | 整组同种方块被**白色整体轮廓**圈出（透视，被方块挡住也能看见），准星旁显示「**待连锁：N 块**」 |
| 2 | 挖掉其中一块 | 连锁开始：其余方块按可触及性标成**绿 / 红**，HUD 显示「**剩余：N 块（可挖 M）**」 |
| 3 | 移动 | 绿 / 红**实时刷新**，新够得到的目标自动转绿并进入挖掘队列 |
| 4 | 结束 | 全部挖完 **或** 按 **X**（强制停止）；可选「松开热键停止」 |

- **打开配置界面**：`` ` `` + **C**（也可从 ModMenu 的模组列表进入）。
- 触发热键与强制停止键都**允许同时按着其他键**，走位时无需松手。
- 中途关掉总开关或连锁采集开关，正在进行的连锁会立刻停止。

## 二、连锁判定规则

- 以被挖方块为起点做**含对角的 3×3×3 邻域**洪水扩展（26 邻域，不只是 6 个面）。
- 默认**同种方块**即算（忽略朝向等方块状态）；开启「精确状态匹配」后只连锁状态完全相同的方块（例如只连同一朝向的原木）。
- 「跳过方块实体」默认开启：箱子、熔炉这类带方块实体的方块不参与连锁，避免内容物丢失。
- 「连锁上限」默认 **128** 块（可设 1–1024）；「方块黑名单」中的方块 id 永不参与。

## 三、挖掘执行：模拟真人挖掘，不是瞬间删除

- 每一块都走**原版交互路径**（`attackBlock` / `updateBlockBreakingProgress`）：真实破坏动画、掉落物、工具耐久消耗、附魔与效率加成，服务端照常校验——**不是**直接删除方块。
- 「**挖掘进度阈值**」决定何时由模组自行发送停止包：`100` = 等待完整破坏，与原版时序完全一致；`70` 是服务端能接受的最低值（约快 30%）。
- 「**挖掘间隔**」：挖完一块后等待 N 个游戏刻再挖下一块（20 刻 = 1 秒，0 = 不等待）。
- **创造模式 + 挖掘间隔 0**：在同一刻破坏所有可触及目标（走原版瞬间破坏判定；生存模式下效率 V + 急迫 II 的「秒破」同理合法）。
- 「**自动停止秒数**」默认 5 秒：这么久内没有任何挖掘进展就自动停止（例如剩余目标都够不到）。**按住热键期间倒计时不推进**，松开后才开始计时；倒计时文本画在数量**下一行**（如「3 秒后停止」，≤3 秒转红），并且**只在可挖方块为 0** 时出现。
- 「松开热键停止」默认**关闭**：默认必须挖完或按强制停止键才结束。
- **单人暂停（Esc 菜单）时整条状态机冻结**：不发挖掘包、不刷新预览、倒计时也不走；取消暂停后从原处继续。

## 四、可达性与颜色

- 「**触及距离**」默认 0 = 使用原版方块交互距离；可设为最远 32 格。
- 「**需要视线可达**」默认**关闭**（开启后要求目标与玩家之间有清晰视线）。
- 「**可触及颜色**」默认绿 `#00FF00`、「**不可触及颜色**」默认红 `#FF0000`——两者均为**纯 RGB** 颜色，填充不透明度由「**高亮不透明度**」（默认 20%）统一控制；未开「绘制边框」时呈现纯填充（MiniHUD 形状渲染器观感）。
- 「**创造模式无视距离**」三档（默认**单人**）：
  - **关** —— 一律使用原版触及距离；
  - **单人** —— 创造模式下，在本机开的世界里彻底解除触及检查；
  - **全部** —— 同上，并且在服务端装有 **Servux** 时，把整组目标当作**一次区域编辑**交给服务端删除（专用服务器上唯一能无视距离的途径；代价是不掉落任何物品、不触发相邻方块更新、且只能编辑已加载的区块）。服务端未装 Servux 时自动退化为普通连锁挖掘。

> Servux 通道的字节级细节见 [docs/servux-task-packet.md](docs/servux-task-packet.md)。

## 五、渲染细节

- **白色预览轮廓**：整组的**最外轮廓**（共面接缝去重；单方块显示完整立方体外框），**透视**绘制，线宽 = 「线宽」（默认 2.0）。
- **红绿目标**有两种模式，随热键自动切换：
  - **按住热键时** —— 逐面透视渲染（只画朝外的面，隔墙可见）；
  - **未按住热键时** —— 整块 box 且受深度测试（会被前方方块遮挡）。
- HUD 计数画在**准星旁**（+14px），可用「显示数量」关闭；预览阶段显示「待连锁：N 块」，连锁中显示「剩余：N 块（可挖 M）」。

## 七、安装与构建

**安装**：需要 Minecraft 1.21.11 + Fabric Loader ≥ 0.19.5 + Fabric API，外加 **malilib**（[sakura-ryoko 的 `LTS/1.21.11` 分支](https://github.com/sakura-ryoko/malilib)，0.27.20 或更新版本）。把 `client_vein_miner-<版本>.jar` 与它们一起放进 `mods/`。ModMenu 可选。

**构建**：Gradle 9.7.0 + Loom 1.17.21，需要 **JDK 21**：

```bash
./gradlew build
```

产物为 `build/libs/client_vein_miner-<版本>.jar`。malilib 依赖来自 `https://masa.dy.fi/maven/sakura-ryoko`（`build.gradle` 已配置）。

## 八、技术规格

- **Minecraft 1.21.11** + **Fabric**（Loader 0.19.5、Fabric API 0.141.6+1.21.11），**Java 21**。
- 配置与热键基于 **malilib**（sakura-ryoko 的 `LTS/1.21.11` 分支，0.27.20）：完整的键位分类「连锁采集 热键」、可搜索的配置界面、ModMenu 集成。
- 内置 **en_us / zh_cn** 两套语言（各 57 键，键集合完全一致）。
- 5 个客户端 mixin：破坏方块回调、原版手动挖掘抑制、触及距离解除、世界 tick 管理器访问、破坏冷却访问。
